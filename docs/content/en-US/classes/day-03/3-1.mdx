### A primeira parede

If your house is a web application, and in the previous lesson we built its foundation with `.nvmrc`, we can say that the walls of the house can be made by **Next**.

{/* ![](/img/dia-03/3-1/01.png) */}

**Next.js** is a web development framework, one of several that exist.

And in these initial hours it is common to be indecisive about which one to choose, and even suffer from:

{/* ![](/img/dia-03/3-1/02.png) */}

{/* ![](/img/dia-03/3-1/03.png) */}

But don't worry, it's a framework that will have little influence on the way you build a website. It won't dictate which furniture should go inside the house (React will do that, lol), or how many rooms it should have, for example.

It will limit itself to providing the structure that will house your application, regardless (or at least very little dependent) on who it is.

### The material list | package.json

Okay, but before we build a wall, we need bricks, cement, and tools, right?

Well, throughout your journey as a dev contractor, you will need a well-defined list of materials before starting any stage of construction. And that's exactly what we use **package.json** for.

The **package.json** is a manifest that will gather important information about your application.

{/* ![](/img/dia-03/3-1/06.png) */}

And one of these pieces of information is nothing more or less than the project's materials list (**dependencies**), in which we register the libraries/modules/resources needed to build and keep the system running.

And also specifying the type of each one (its **version**) to avoid compatibility problems in the future.

{/* ![](/img/dia-03/3-1/07.png) */}

To create the **package.json**, just run the command `npm init` and fill in the data in the terminal initially. After that, every new item registration in the bill of materials (dependencies) must be done with the command `npm install`.

{/* ![](/img/dia-03/3-1/08.png) */}

It asks for some information, let's leave everything as default except the last one about the license.

{/* ![](/img/dia-03/3-1/09.png) */}

At the end it shows you a summary for you to review before the creation is completed.
