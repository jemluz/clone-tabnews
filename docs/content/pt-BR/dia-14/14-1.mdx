# Inauguração da Milestone 1: Fundação

Se você ficou feliz com os conhecimentos adquiridos com a conclusão da Milestone 0…

{/* ![](/img/dia-14/14-1/01.png) */}

… você irá gostar muito mais dos conhecimentos que irá adquirir agora na Milestone 1!

### Modelo mental

Vou propro um modelo mental para você: na Milestone 0 nós abrimos um buraco, como um terreno com nosso nome.

{/* ![](/img/dia-14/14-1/05.png) */}

e agora vamos descobri o que será colocado aí dentro

- Se for um arranha céu
- Se for uma casa
- Se for um barraco

Cada cenário vai pedir necessidades diferentes na sua fundação

### Criando a Milestone 1

Então vamos lá, o caminho você já conhece…

{/* ![](/img/dia-14/14-1/18.png) */}

{/* ![](/img/dia-14/14-1/19.png) */}

Vamos add uma Issue sobr arquitetura de software e a organização de arquivos pastas do projeto.

{/* ![](/img/dia-14/14-1/20.png) */}

{/* ![](/img/dia-14/14-1/21.png) */}

A próxima issue é sobre criar um fluxo de Testes Automatizados.

{/* ![](/img/dia-14/14-1/22.png) */}

O próximo item vai tratar de Banco de Dados (Local)

{/* ![](/img/dia-14/14-1/23.png) */}

{/* ![](/img/dia-14/14-1/24.png) */}

A próxima é uma issue de Migrations, fundamental para deixar o trabalho com Banco de Dados algo profissional.

{/* ![](/img/dia-14/14-1/25.png) */}

A próxima issue é de CI (Continuous Integration), que vai servir para proteger todo mundo de fazer besteira com o projeto. Capturar comportamentos errados causados por coisas que nunca iam passar pelo nosso radar humano.

E evitar você de soltar pérolas como “poxa mas na minha máquina funciona”

{/* ![](/img/dia-14/14-1/26.png) */}

Próxima: Linter de código

Ué mas a gente num já tem um? Sim, mas é um linter de estilo. Esse novo Linter tem a ver com a exatidão do código.

Além de que vamos engatar essas coisas no fluxo do continuous integration. Para que o CI diga se está tudo ok ou não.

{/* ![](/img/dia-14/14-1/27.png) */}

A próxima issue é um Linter de commits. Segue a mesma lógica dos outras mas agora direcionado as mensagens de commits.

{/* ![](/img/dia-14/14-1/28.png) */}

Próxima issue: Banco de Dados (Homologação e Produção), onde veremos também sobre algo importantíssimo que são as variáveis de ambiente.

{/* ![](/img/dia-14/14-1/29.png) */}

{/* ![](/img/dia-14/14-1/30.png) */}

E por fim, uma issue para Tipo da Licença

Esse é um tópico que gera muita dúvida, principalmente se eu posso copiar algo open source e usar comercialmente, ou se outras pessoas podem roubar o que eu disponibilizei de forma open source
