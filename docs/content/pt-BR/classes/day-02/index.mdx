# Git? Github? É tudo a mesma coisa?

<Callout emoji="⚠️">
Confundir **git** com **github** é o mesmo que confundir ter um **arquivo .mp4** no seu PC com ter o **YouTube** nele.
</Callout>

{/* ![](/img/dia-02/index/01.png) */}

### O Git é...

uma pasta - **uma ferramenta** - que **monitora alterações** no seu projeto/código localmente.

### O Github é...

a **rede social** onde você disponibiliza seu código **(monitorado pelo git)** em seu perfil para que outras pessoas interajam com você e para que você interaja com o código delas.

{/* ![](/img/dia-02/index/02.png) */}

> Em outras palavras: 
> → o **Github** **está para o** **Git** 
> assim como: 
> → o **Youtube** está para um **arquivo MP4**
