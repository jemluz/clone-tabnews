# Sincronização das configurações do Editor

Vamos adicionar 3 subtarefas na issue de estilização de código

{/* ![](/img/dia-10/10-1/01.png) */}

Para se proteger de perdas da instancia vs code no github, você pode usar o settings sync que irá salvar as config do seu editor na nuvem

{/* ![](/img/dia-10/10-1/02.png) */}

Na parte inferior esquerda seleciona “Turn on Settings Sync”

{/* ![](/img/dia-10/10-1/03.png) */}

Realize o login

{/* ![](/img/dia-10/10-1/04.png) */}

Pronto, se você deletar a sua instancia do vs code agora, e criar outra, poderá recuperar as config do editor através do Settings Sync

Você pode marcar a primeira tarefa como concluída

{/* ![](/img/dia-10/10-1/05.png) */}
